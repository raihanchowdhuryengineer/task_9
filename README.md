# AIT Portfolio Website – Sample Student Work

This is a **sample of student work** for Applied Information Technology ATAR Year 11, Task 9: *Portfolio Website Using HTML/CSS*.

It shows the standard expected for the website part of the task. "Sample Student" is a fictional student, and the projects shown are example work.

- **School:** Sunshine Grammar School and College
- **Prepared by:** Abdullah Md Raihan Chy (teacher)
- **Course:** WACE Applied Information Technology ATAR Year 11 (SCSA)

## Pages

| Page | Contents |
|---|---|
| `index.html` | Home page with an introduction and featured work |
| `projects.html` | Three projects, each with an image and short description |
| `assessments.html` | Every assessment task in the course, marked completed or upcoming |
| `classwork.html` | Classwork from lessons |
| `references.html` | References for work not created by the student |

All pages use one external stylesheet, `css/style.css`. The HTML and CSS pass the W3C Nu validator with no errors.

## View the site

Open `index.html` in a web browser, or view it online with GitHub Pages.
